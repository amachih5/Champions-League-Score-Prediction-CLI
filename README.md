## 概要
CLのスコア/勝ち点予想CLIです。<br>
予想と現実スコアが合っていたら、+3ポイント、ハズレ-3ポイントというギャンブル性があります🎰
<br>
<b>※当然ながらお金はかけられません。</b><br>

<b>現実のスコアリンク</b><br>
[Champions League Match Results](https://uefa.com)<br>
↑リンクにある実際の試合のスコアと自分の予想スコアを比べます。
